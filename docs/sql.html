SQL for Data Analysis

This chapter is the summary of the online course: https://www.dataskool.org/courses and the UofSc course Computing in Statistics.

Before discussing SQL codes, we need to connect to a database. There are so many different ways to connect to a database. However, if someone is working in the R environment, then the below steps can be followed.

The first step in retrieving data with SQL queries is to create a connection to a database. We will do this from within R using the library mdsr, which enables connection to a database called “airlines” stored on an Amazon Web Services server. The following R commands establish the connection:

library(mdsr) 
db <- dbConnect_scidb("airlines") # establish a connection to the database "airlines"

The airlines database contains information on about 18 million flights between US airports taking place during the years 2013–2015.

Now that we have created a connection to a database, we can submit SQL queries to retrieve data from it. If we are compiling a .qmd document in Rstudio, we can execute SQL in a code chunk. We just need to open the code chunk with {sql connection=<db>}, where <db> is whatever you have named the database connection.

There are three specific types of merging:

  • Inner Join On: If you care about the intersection of the data-sets.

  • Left Join On: Put more emphasize on the left table.

  • Right Join On: Put more emphasize on the right table.

  • Full Join On: When you want to keep all rows from both tables, which may introduce incomplete rows.

Sometimes we may need to stack one table with another, which is described as union in SQL.

select * from students
union
select * from students_2
-- this will keep only the unique rows
-- however, to keep all of the rows
select * from students
union all
select * from students_2

By using union, we can create custom tables.

select 'airports' as table_name, count(*) as row_num 
from airports
union
select 'flights', count(*)
from flights
union
select 'carriers', count(*)
from carriers

Another important concept is creating temporary table.

with table_summary as (
select 'airports' as table_name, count(*) as row_num 
from airports
union
select 'flights', count(*)
from flights
union
select 'carriers', count(*)
from carriers)
select * from table_summary
3 records
table_name row_num
airports 1458
flights 18008372
carriers 1610

Creating temporary table in this way is called ‘Common Table Expression’. Above results can be produced by the below way also.

-- another of doing the above
select * from 
(
select 'airports' as table_name, count(*) as row_num

union

from flights

from carriers
